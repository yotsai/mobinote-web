アカウントの削除

最終更新日: 2026年6月24日

MobiNote（モビノート）のアカウントと、それに紐づくすべてのデータの削除方法をご案内します。削除はいつでもご自身で行えます。

アプリ内で削除する（推奨）

MobiNoteアプリから、いつでもご自身でアカウントを削除できます。

  1. MobiNoteアプリを開く
  2. 「アカウント」画面を開く
  3. 「アカウントとデータを削除」をタップする
  4. 確認メッセージで削除を実行する

実行すると、アカウントと保存されているすべてのデータがその場で完全に削除されます。この操作は取り消せません。

メールで削除を依頼する

アプリを利用できない場合は、メールで削除をご依頼いただけます。

宛先：mobinote.app@gmail.com

件名：アカウント削除依頼

本文：ご登録のメールアドレスを明記してください。本人確認のため、登録済みのメールアドレスからご送信をお願いします。

内容を確認のうえ、原則として7日以内にアカウントと関連データを削除します。

削除されるデータ

  • アカウント情報（メールアドレス）
  • 登録した車両情報
  • 給油・整備・費用などのすべての記録
  • アップロードした書類・車両の写真
  • アプリの利用に関する設定・データ

これらのデータは、サーバーおよびバックアップから削除されます。

データの保持について

削除リクエスト後、データは速やかに削除されます。法令により保持が義務付けられている情報（該当する場合）を除き、バックアップからも所定の期間内に消去されます。
